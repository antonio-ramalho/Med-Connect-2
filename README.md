# Med Connect 🏥

## 📌 Sobre o Projeto
O **Med Connect** é uma plataforma médica desenvolvida durante o meu 2º semestre do curso de Engenharia de Software. O objetivo principal do sistema é digitalizar e centralizar todo o processo de atendimento ao paciente, criando um fluxo de dados contínuo que acompanha o usuário desde a recepção até o momento do atendimento médico no consultório.

## 🚀 Tecnologias e Arquitetura
A arquitetura do projeto foi desenhada de forma direta, focada em múltiplas operações de CRUD (Create, Read, Update, Delete) para gerenciar o fluxo de pacientes, médicos e agendamentos.
* **Linguagens:** PHP, JavaScript, HTML5, CSS3.
* **Controle de Versão:** Git/GitHub.
* **Design:** Figma.
